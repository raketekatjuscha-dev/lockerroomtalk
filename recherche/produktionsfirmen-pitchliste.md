# LOCKER ROOM TALK – Pitchliste Produktionsfirmen (Stand: 11.10.2026)

Format: Gesprächsformat, 30–40 Min., Host Katja Lewina, eine Gästin pro Folge, Setting Umkleidekabine,
Mediathek + YouTube + Podcast. Buch „Bye Bye Boys“ erscheint am 9.2.2027.

Wichtiger Hinweis vorab: Produktionsfirmen finanzieren in Deutschland selten aus eigener Tasche. Sie entwickeln
mit euch und verkaufen an einen Sender oder eine Plattform. Wirklich eigenes Geld (Werbung, Branded Content,
Plattform-Budget) bringen hier nur Brainpool/Banijay, Seven.One Audio, Studio Flitz, Studio Bummens und Podimo mit.

Vertrauen: ✅ = 2025/26 belegt · ⚠️ = Quelle älter oder widersprüchlich, vor dem Anschreiben im Impressum oder auf LinkedIn prüfen.
